# Подготовка BRD для этого проекта

Следуй `AGENTS.md` проекта: в нём заданы структура BRD, оформление и формат результата. Используй приложенные файлы с требованиями как источники содержания, а не как образцы оформления, если пользователь прямо не назвал их шаблонами.

## Анализ источников

- Выдели из предоставленных материалов бизнес-цели, этапы процессов, правила, требования, роли, данные, интеграции, уровни обслуживания и измеримые показатели.
- Разделяй подтверждённые факты, допущения и открытые вопросы. Не придумывай недостающие бизнес-факты. Противоречия между источниками фиксируй как открытые вопросы с контекстом, достаточным для их разрешения.
- Присваивай требованиям, Use Cases и User Stories устойчивые идентификаторы. По возможности указывай источники и показывай связи между элементами в матрице трассируемости.

## Подготовка BRD

Охвати разделы, перечисленные в `AGENTS.md`, соразмерно объёму исходных сведений и запросу пользователя. Всегда выделяй отдельные разделы для Use Cases и User Stories, даже если их нет в исходных материалах. Формируй предлагаемые сценарии и истории на основе подтверждённых требований; неопределённое поведение помечай как требующее согласования.

Для каждого Use Case укажи идентификатор и название, цель, участников, предусловия, событие запуска, основной поток, альтернативные и исключительные потоки, постусловия, связанные бизнес-правила или требования. Для каждой User Story укажи идентификатор, роль, потребность, бизнес-ценность, критерии приёмки (предпочтительно в формате Given/When/Then) и связи с Use Cases или требованиями.

Формулируй требования кратко и так, чтобы их можно было проверить. Если для раздела нет подтверждённых сведений, обозначь пробел и вынеси необходимое решение в открытые вопросы.

## Подготовка и проверка файла

Для нового BRD используй стиль `standard_business_brief`, если пользователь не запросил другое оформление. Подготовь визуально проверенный файл `.docx`, если не запрошен другой формат. При создании Word-документа и проверке страниц следуй доступному скиллу для работы с документами; исправь существенные проблемы с оформлением до передачи результата.

В итоговом ответе дай ссылку на файл и кратко укажи наиболее важные открытые вопросы.
